# ytbd — получение и проверка данных YouTube

Проект для получения выбранных общедоступных данных YouTube, сохранения исходных результатов и проверки их структуры. Сохранённый снимок AsForJS — тестовый пример, а не адрес канала, зашитый в сборщик.

## Получить данные канала

### 1. Установи yt-dlp

Следуй [официальной инструкции](https://github.com/yt-dlp/yt-dlp#installation). Проверь, что программа доступна в терминале:

```sh
yt-dlp --version
```

Для запуска сборщика нужен Python 3.10 или новее.

### 2. Открой терминал в корне репозитория

Вставь URL нужного канала и выбери типы данных. Например:

```sh
python3 scripts/collect.py \
  --url "https://www.youtube.com/@AsForJS" \
  --data channel,videos,playlists \
  --method yt-dlp \
  --output ./data/AsForJS
```

Замени URL на адрес другого канала. Имя AsForJS в примере — обычный параметр, не настройка внутри скрипта.

Доступные значения `--data`:

- `channel` — метаданные страницы канала;
- `videos` — список видео;
- `playlists` — плейлисты канала;
- `streams` — вкладка трансляций;
- `podcasts` — вкладка подкастов, если она доступна.

Можно выбрать один тип или несколько через запятую. Результаты сохраняются в отдельные JSON-файлы в указанном каталоге. Повторный запуск заменяет файлы с теми же именами.

### 3. Выбери только нужные данные

Например, получить только список плейлистов:

```sh
python3 scripts/collect.py \
  --url "https://www.youtube.com/@AsForJS" \
  --data playlists \
  --output ./data/AsForJS
```

Пока реализован только метод `yt-dlp`. Параметр метода указан явно, чтобы будущие способы получения данных можно было добавить как отдельные реализации, а не смешивать их логику в одном скрипте. YouTube может менять доступность вкладок и состав возвращаемых данных; проверяй сообщения сборщика и полученные файлы.

## Проверить сохранённый тестовый снимок — без сети

Проверка снимка не запускает сбор и не обращается к YouTube:

```sh
python3 scripts/validate_snapshot.py
```

На GitHub ту же проверку можно запустить через [Actions](https://github.com/devAItester/ytbd/actions), выбрав **Проверка сохранённого снимка AsForJS** и нажав **Run workflow**.

## Тесты сборщика

Тесты проверяют разбор URL, маршрутизацию вкладок и построение команды без сетевых запросов:

```sh
python3 -m unittest discover -s tests -v
```

## Пример сохранённых исходных данных

Каталог [`examples/AsForJS/`](examples/AsForJS/) хранит исторические данные, логи и материалы прежнего сбора. Он используется для анализа и регрессионной проверки. Сборщик не читает этот каталог как источник URL и не перезаписывает его.

Дополнительные материалы: [метод сбора](docs/collection-method.md), [жизненный цикл данных](docs/data-lifecycle.md), [оценка инструментов](docs/tool-evaluation.md).

## Текущие границы

- На этом этапе входной объект — URL страницы канала.
- Реализован один источник получения: `yt-dlp`; API и RSS пока не реализованы.
- Выбор субтитров, комментариев, подробностей каждого видео и загрузки медиа — отдельные задачи, которые нужно подключать явно.
- Сбор может завершиться частично, если YouTube или отдельная вкладка недоступны. Проверяй статус и результат, прежде чем считать архив полным.
- Не сохраняй в репозитории cookies, браузерные профили, токены или другие секреты.
