# ytbd — данные YouTube через веб-интерфейс GitHub

Добавляй адреса каналов в файл, запускай обработку в GitHub Actions и смотри результат прямо в репозитории. Локальный терминал для обычного запуска не нужен.

## Меню функций

1. **Добавить адреса каналов** — [открыть `config/channels.txt`](config/channels.txt). Нажми карандаш (Edit), добавь по одному URL на строку и сохрани изменения через Commit changes.
2. **Выбрать, сколько адресов обработать** — при запуске укажи число последних непустых строк. По умолчанию — **4**. Пустые строки и строки с `#` игнорируются.
3. **Настроить вид страницы канала** — [редактировать `templates/channel.md`](templates/channel.md). Доступны поля `{{title}}`, `{{url}}`, `{{channel_id}}`, `{{updated_at}}`, `{{item_count}}`, `{{items}}`.
4. **Создать или обновить каталоги каналов** — [открыть workflow «Обновить представления каналов»](../../actions/workflows/process-channels.yml) и нажать **Run workflow**. Оставь ветку `main`, укажи количество последних строк и запусти workflow.
5. **Посмотреть результаты** — [каталог `data/channels/`](data/channels/). Для каждого обработанного канала создаются папка, `README.md` по шаблону и `channel.json` с исходными данными.
6. **Проверить тестовый снимок и логику без сети** — [открыть GitHub Actions](../../actions/workflows/validate-snapshot.yml). Эта проверка не запускает сбор с YouTube.

## Как это работает

- Входной список хранится в `config/channels.txt`; адреса не зашиты в код.
- Workflow читает указанное число последних непустых строк списка и проверяет, что это URL каналов YouTube.
- Для каждого адреса запускается `yt-dlp`; создаётся каталог с именем канала.
- `README.md` формируется из редактируемого шаблона, а `channel.json` хранит ответ источника.
- Workflow сохраняет созданные и обновлённые файлы обратно в репозиторий. Изменения в `data/channels/` сами по себе не запускают workflow повторно.

## Границы первой версии

- Обрабатываются URL страниц каналов YouTube, а не отдельные URL видео или плейлистов.
- Реализован один источник данных — `yt-dlp`. YouTube Data API и RSS пока не подключены.
- Число **4** означает количество последних адресов в файле, а не число последних видео на каждом канале.
- Список видео, который возвращает YouTube, зависит от доступности страницы и поведения источника; перед выводами об архиве проверяй результат запуска.
- Workflow может записывать результаты в репозиторий, поэтому изменения доступны всем, кто имеет к нему доступ. Не добавляй cookies, токены и другие секреты.
