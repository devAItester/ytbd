# HTML-представления

После запуска workflow здесь создаются страницы по выбранному шаблону:

- outline.html — компактный обзор со сворачивающимися разделами;
- archive.html — подробные таблицы;
- index.html — краткий индекс.

Для каждого канала используется отдельный подкаталог. Страницы генерируются из сохранённого архива, поэтому шаблон можно сменить без повторного сбора исходных данных.
