# Представления для просмотра на GitHub

После запуска workflow здесь создаются Markdown-страницы по выбранному шаблону:

- outline.md — компактный обзор со сворачивающимися разделами;
- archive.md — подробные карточки с метаданными;
- index.md — краткий индекс.

Для каждого канала используется отдельный подкаталог. В шаблонах используются HTML-теги <details> и <summary>, которые GitHub отображает как раскрывающиеся блоки внутри Markdown. Страницы генерируются из сохранённого архива, поэтому шаблон можно сменить без повторного сбора исходных данных.
