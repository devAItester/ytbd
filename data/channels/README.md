# Сохранённые данные каналов

После запуска workflow для каждого канала создаётся каталог со следующими материалами:

- channel.json — последний успешно полученный ответ с метаданными канала;
- raw/ — последние успешно полученные JSON-ответы вкладок videos, streams, podcasts и playlists;
- archive/ — накопленные записи, включая те, которые больше не встречаются в текущем списке;
- status.json — время последней проверки, число записей и ошибки;
- logs/ — диагностика неудачных запросов, если источник её вернул.

Неудачный запрос не заменяет последний успешно сохранённый JSON. Архив не удаляет записи автоматически.
