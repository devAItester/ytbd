# Результаты обработки каналов

Здесь появляются каталоги каналов после запуска [workflow «Обновить представления каналов»](https://github.com/devAItester/ytbd/actions/workflows/process-channels.yml).

Для каждого канала сохраняются:
- `README.md` — представление по шаблону;
- `channel.json` — исходные данные, возвращённые `yt-dlp`.

Этот файл служит указателем до первого запуска.
